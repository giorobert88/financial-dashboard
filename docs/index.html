100% Private & Self-Hosted

Your financial data stays within your local network. Includes a built-in Privacy Demo Mode to dynamically mask balances and account names when taking screenshots or presenting.

Safe-To-Spend Algorithm

Know exactly how much you can spend. Computes disposable limits by resolving current asset balances, pending card payments, and cycle recurring bills automatically.

Inbox Queue Categorization

Instantly sort uncategorized purchases made over the last 7 days. Simple one-tap categorizing syncs back to Firefly III instantly using an optimized client cache flow.

Metadata-Driven Automations

Define card strategies and payment intervals. Rules are saved back to Firefly III notes fields dynamically, keeping the setup database-agnostic.

Mobile-First Layout

Designed as a progressive web view. Enjoy swift interactions, bottom touch navigation, and lightweight rendering performance tailored for smartphones.

Pre-Built Docker Image

Runs natively via Docker Compose. Multi-arch support is built-in (works out of the box on Raspberry Pi ARM64 and standard x86 servers) without local build overhead.

Deploy in Minutes

Quick-start commands to configure and host the dashboard on your infrastructure.

# Clone the repository
git clone https://github.com/giorobert88/financial-dashboard.git
cd financial-dashboard
# Configure local environment vars
cp .env.example .env.local
nano .env.local
# Install and run development environment
npm install
npm run dev
# Create docker-compose.yml and .env.local, then:
docker compose up -d
# Monitor container startup logs
docker compose logs -f
